# Паспорт космического аппарата «Периметр-1»

Документ: ПА-П1-003, редакция 5 (последняя правка — 12.10.2023, после завершения миссии).
Хранитель документа: Отдел наблюдательной космологии ИПК им. А. Н. Квадратова.

## 1. Общие сведения

| Параметр | Значение |
|---|---|
| Полное наименование | Периметр-1 (Первый периметрический обсерваторный аппарат) |
| Заказчик | Институт плоской космологии им. А. Н. Квадратова |
| Изготовитель | НПО «Тупой Угол» |
| Научный руководитель миссии | И. И. Хордова (с 2009 г.; до 2009 г. — Б. Г. Эллипсов) |
| Главный конструктор | В. Ф. Катетов (НПО «Тупой Угол») |
| Дата запуска | 8 апреля 2011 г. |
| Место запуска | космодром Тупой Угол, стартовая дуга № 2 |
| Ракета-носитель | «Биссектриса-М» |
| Масса при запуске | 1 840 штрихов |
| Масса научной аппаратуры | 412 штрихов |
| Масса топлива | 610 штрихов |
| Энергопитание | солнечная линейка 19 плинтов, 2,6 квт-эквивалента |
| Орбита | гелиоцентрическая, вдоль орбиты Обода, отставание ~0,01 оборота |
| Начало научной программы | 1 сентября 2011 г. |
| Завершение научной программы | 30 сентября 2023 г. |
| Статус | научная программа завершена; аппарат переведён в режим пассивного дрейфа |

## 2. Научная аппаратура

| Прибор | Назначение | Характеристика |
|---|---|---|
| ОТ-24 | оптический телескоп | апертура 2,4 плинта, поле 0,9° |
| РГ-3 | радиометр реликтового гула | чувствительность 0,6 мпК за сутки Обода |
| ТЛ-1 | толщиномер (лазерный интерферометр) | база 140 плинтов |
| ЗВ-2 | датчик заряженных частиц | 14 каналов |
| ГЛ | «Глазок» — служебная камера | для фотографий Обода и для прессы |

Примечание к ТЛ-1: именно данные этого прибора, объединённые с наземным толщиномером ТМ-7, позволили в 2021 г. получить верхнюю границу толщины Плоскости 3·10⁻⁴¹ плинта.

## 4. Реквизиты для архивных запросов

- Архив данных: сервер «Ордината», раздел /perimetr1/final
- Объём архива: 214 терабит
- Формат: fits-2d
- Ответственный за архив после 2023 г.: Я. О. Отрезкина

## 5. Особые отметки

1. Бортовое имя аппарата в переписке разработчиков — «Перик». Официально не используется, но встречается в журналах.
2. Проект аппарата «Периметр-2» в 2025 г. находится на стадии обсуждения концепции; финансирование не открыто, параметры не утверждены.
3. На корпусе закреплена табличка с именами всех 1 204 сотрудников ИПК и НПО «Тупой Угол», работавших над аппаратом, — совпадение с числом полей обзора ОБХОД-2 случайно (по крайней мере так утверждает Хордова).
